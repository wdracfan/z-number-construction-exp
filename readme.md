Репозиторий содержит программный код вычислительных экспериментов, проведённых в рамках выполнения выпускной квалификационной работы "Методология построения Z-чисел для представления наборов данных" на образовательной программе "Программная инженерия" факультета компьютерных наук НИУ ВШЭ.

Для запуска всех экспериментов нужно выполнить команду:
```bash
python3 -m main
```
Результаты экспериментов сохраняются в отдельной папке `experiments`, которая должна лежать на одном уровне с корнем репозитория.
